# Validation Reports

This folder contains public-safe validation reports for Empire Breacher research phases.

## Reports

- [Phase 3 Wallet-Agent Evaluation](phase-3-wallet-agent-evaluation.md)

## Purpose

Validation reports summarize what was tested, how the test was evaluated, what the results mean, and what limitations apply.

These reports are intended to make the project results reviewable without requiring readers to inspect every fixture or tool file first.
