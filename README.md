\# empire-breacher



Offensive research at the intersection of AI agents and crypto financial rails.



This repo contains:



\- \*\*research/\*\* – taxonomies and threat models for AI agent financial attacks

\- \*\*exploits/\*\* – proof-of-concept code (e.g., AI-driven wallet hijack on Ethereum testnet)

\- \*\*tools/\*\* – utilities for testing prompt injection and agent robustness



Initial focus: prompt injection and tool misuse leading to unauthorized blockchain transactions.
